# Инструкция по демонстрации Network запросов и MinIO

## 1. Настройка MinIO для работы с изображениями

### Шаг 1.1: Запуск MinIO через Docker Compose

```bash
# В корневой директории проекта
docker-compose up -d
```

Это запустит:
- MinIO серверы (4 инстанса)
- Nginx для балансировки нагрузки
- MinIO будет доступен на `http://localhost:9000`

### Шаг 1.2: Настройка MinIO через веб-интерфейс

1. Откройте MinIO Console: `http://localhost:9001`
2. Войдите с учетными данными:
   - Access Key: `minio`
   - Secret Key: `minio124`
3. Создайте bucket с именем `gases`:
   - Нажмите "Create Bucket"
   - Введите имя: `gases`
   - Нажмите "Create Bucket"
4. Настройте публичный доступ к bucket:
   - Выберите bucket `gases`
   - Перейдите в "Access Policy"
   - Установите "Public" или "Download" для чтения файлов

### Шаг 1.3: Загрузка изображений в MinIO

**Вариант 1: Через веб-интерфейс**
1. Откройте bucket `gases`
2. Нажмите "Upload"
3. Загрузите изображения газов
4. Скопируйте URL загруженного файла (например: `http://localhost:9000/gases/hydrogen-1234567890.jpg`)

**Вариант 2: Через API бэкенда**
```bash
curl -X POST http://localhost:8080/api/gases/1/image \
  -F "file=@path/to/hydrogen.jpg"
```

### Шаг 1.4: Обновление URL изображений в БД

После загрузки изображений в MinIO, обновите `image_url` в базе данных:

```sql
UPDATE gas 
SET image_url = 'http://localhost:9000/gases/hydrogen-1234567890.jpg' 
WHERE id = 1;

UPDATE gas 
SET image_url = 'http://localhost:9000/gases/oxygen-1234567890.jpg' 
WHERE id = 2;
-- и так далее для всех газов
```

### Шаг 1.5: Настройка CORS для MinIO (если нужно)

Если изображения не загружаются из-за CORS, настройте CORS в MinIO:

1. Откройте MinIO Console
2. Перейдите в "Settings" → "CORS"
3. Добавьте правило:
   - Allowed Origins: `http://localhost:3000`
   - Allowed Methods: `GET, HEAD`
   - Allowed Headers: `*`
   - Max Age: `3600`

## 2. Демонстрация Network запросов через Proxy

### Шаг 2.1: Открытие DevTools

1. Запустите фронтенд: `npm run dev` (в папке `gase-frontend`)
2. Откройте браузер: `http://localhost:3000`
3. Откройте DevTools: `F12` или `Ctrl+Shift+I` (Windows) / `Cmd+Option+I` (Mac)
4. Перейдите на вкладку **Network**

### Шаг 2.2: Показ запросов к API через Proxy

1. **Перейдите на страницу газов**: `http://localhost:3000/gases`

2. **Найдите запрос к API**:
   - В Network найдите запрос `gases` или `gases?search=...`
   - Обратите внимание на колонки:
     - **Name**: `gases` или `gases?search=...`
     - **Status**: `200` (успешно) или `500` (ошибка)
     - **Type**: `fetch` или `xhr`
     - **Initiator**: `gasApi.ts:XX` (файл, который инициировал запрос)

3. **Покажите детали запроса**:
   - Кликните на запрос
   - Перейдите на вкладку **Headers**
   - Покажите:
     - **Request URL**: `http://localhost:3000/api/gases`
     - Объясните: запрос идет на фронтенд сервер (порт 3000), а не напрямую на бэкенд
   
4. **Покажите проксирование**:
   - В **General** секции покажите:
     - **Request URL**: `http://localhost:3000/api/gases`
   - Объясните: Vite проксирует этот запрос на `http://localhost:8080/api/gases`
   - Покажите файл `vite.config.ts`:
     ```typescript
     proxy: {
       "/api": {
         target: "http://localhost:8080",
         changeOrigin: true,
         rewrite: (path) => path.replace(/^\/api/, "/api"),
       },
     }
     ```

5. **Покажите ответ**:
   - Перейдите на вкладку **Response**
   - Покажите JSON ответ с данными газов
   - Обратите внимание на структуру данных:
     ```json
     [
       {
         "ID": 1,
         "Title": "Водород",
         "Formula": "H₂",
         "MolarMass": 2.016,
         "ImageURL": "http://localhost:9000/gases/hydrogen-1234567890.jpg",
         ...
       }
     ]
     ```

### Шаг 2.3: Показ запросов к изображениям из MinIO

1. **Найдите запросы к изображениям**:
   - В Network найдите запросы с типом `img` или `image`
   - Или найдите запросы к домену `localhost:9000`

2. **Покажите детали запроса изображения**:
   - Кликните на запрос изображения (например: `hydrogen-1234567890.jpg`)
   - В **Headers** покажите:
     - **Request URL**: `http://localhost:9000/gases/hydrogen-1234567890.jpg`
     - Объясните: это прямой запрос к MinIO серверу, не через прокси
   
3. **Покажите структуру URL MinIO**:
   - Формат: `http://localhost:9000/{bucket}/{object-name}`
   - Пример: `http://localhost:9000/gases/hydrogen-1234567890.jpg`
   - Где:
     - `localhost:9000` - адрес MinIO сервера
     - `gases` - имя bucket
     - `hydrogen-1234567890.jpg` - имя объекта (файла)

4. **Покажите ответ изображения**:
   - В **Response** покажите, что это бинарные данные изображения
   - В **Preview** покажите само изображение

### Шаг 2.4: Сравнение запросов с mock данными и реальными данными

1. **Запросы с mock данными** (без запущенного бэкенда):
   - В Network покажите запрос `gases` со статусом `500` или `Failed`
   - В Console покажите сообщение: `Error fetching gases, using mock data`
   - Покажите, что изображения загружаются из `/gas-images/hydrogen.svg` (локальные файлы)

2. **Запросы с реальными данными** (с запущенным бэкендом):
   - В Network покажите запрос `gases` со статусом `200`
   - Покажите, что изображения загружаются из `http://localhost:9000/gases/...` (MinIO)

## 5. Типичные проблемы и решения

### Проблема: Изображения не загружаются из MinIO

**Решение:**
1. Проверьте, что MinIO запущен: `docker ps`
2. Проверьте доступность: `http://localhost:9000`
3. Проверьте CORS настройки в MinIO
4. Проверьте, что bucket публичный или настроен правильный доступ

### Проблема: CORS ошибки

**Решение:**
1. Настройте CORS в MinIO Console
2. Или используйте проксирование изображений через бэкенд

### Проблема: Запросы к API не проходят через proxy

**Решение:**
1. Проверьте `vite.config.ts` - настройки proxy
2. Убедитесь, что запросы идут на `/api/...`
3. Перезапустите dev сервер: `npm run dev`

---

## 6. Дополнительные заметки

- Все запросы к API (`/api/*`) проксируются через Vite на бэкенд
- Запросы к изображениям идут напрямую к MinIO (не через proxy)
- Mock данные используются при ошибках API или отсутствии бэкенда
- Локальные изображения находятся в `public/gas-images/`
- Изображения из MinIO имеют URL вида: `http://localhost:9000/gases/{filename}`
