# GaseProject Frontend

React приложение для работы с каталогом газов.

## Технологии

- React 18
- TypeScript
- Vite
- React Router
- React Bootstrap
- Bootstrap 5

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:3000

## Сборка для продакшена

```bash
npm run build
```

## Структура проекта

- `src/pages/` - страницы приложения
- `src/components/` - переиспользуемые компоненты
- `src/modules/` - модули для работы с API
- `src/Routes.tsx` - конфигурация маршрутов

## API

Приложение подключается к бэкенду через прокси на `/api`. Бэкенд должен быть запущен на `http://localhost:8080`.

### Основные эндпоинты:

- `GET /api/gases` - список газов с фильтрами
- `GET /api/gases/:id` - детальная информация о газе

## Фильтрация

На странице списка газов доступны следующие фильтры:

- Поиск по названию/формуле
- Минимальная молярная масса
- Максимальная молярная масса
- Диапазон дат (работает только с mock данными)

## Mock данные

При отсутствии доступа к бэкенду приложение использует mock данные из `src/modules/mock.ts`.
